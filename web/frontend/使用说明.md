## 🎮 交互操作指南

### 基础操作
1. **🎬 开始演示**: 点击"开始演示"按钮启动自动循环演示
2. **⏸️ 暂停控制**: 随时暂停或停止演示
3. **🔄 场景切换**: 点击四个学科按钮切换教学场景
4. **🤏 手势控制**: 控制机械臂执行不同教学手势

### 高级功能
- **🎤 语音测试**: 输入文字测试语音合成功能
- **💬 智能问答**: 模拟学生提问，体验AI回复
- **⚙️ 参数调整**: 调整教学难度、模式、个性化选项
- **📝 日志管理**: 查看、导出、清空系统运行日志

### 快捷键支持
- **Ctrl + 1**: 开始演示
- **Ctrl + 2**: 暂停演示  
- **Ctrl + 3**: 停止演示
