# 智能教育助手机器人

基于RISC-V K1平台的多模态智能教育机器人系统

## 项目概述

本项目为第十六届蓝桥杯大赛数字科技创新赛（RISC-V应用创新）参赛作品，旨在构建一个集成计算机视觉、语音识别、大语言模型和机械臂控制的智能教育助手机器人。

### 核心功能

- **多模态交互**: 语音对话 + 视觉识别 + 文本生成
- **物理操作**: 机械臂演示和指向功能
- **教学辅助**: 知识问答、学习评估、个性化推荐
- **本地AI**: 所有AI推理在K1芯片本地完成，保护隐私

### 技术特色

- 基于RISC-V K1芯片（2.0 TOPS AI算力）
- CV + ASR + LLM三模态深度融合
- 边缘AI部署，实时响应
- 硬件与AI决策深度协同

## 系统架构

```
├── src/
│   ├── vision/          # 计算机视觉模块
│   ├── audio/           # 语音处理模块
│   ├── llm/             # 大语言模型模块
│   ├── fusion/          # 多模态融合引擎
│   ├── control/         # 硬件控制模块
│   └── utils/           # 工具模块
├── config/              # 配置文件
├── docs/                # 项目文档
├── tests/               # 测试代码
└── assets/              # 资源文件
```

## 硬件平台

- **主控**: MUSE Pi Pro开发板（进迭时空K1芯片）
- **视觉**: USB 1080P摄像头 + HDMI触摸屏
- **语音**: USB麦克风阵列 + 扬声器模组
- **执行**: myCobot 280 RISC-V机械臂
- **传感**: ToF激光雷达 + RGB-LED状态指示

## 技术栈

- **AI框架**: ONNX Runtime (RISC-V优化)
- **操作系统**: Bianbu Linux
- **开发语言**: Python + C++
- **通信协议**: ROS2
- **模型**: YOLOv8n + Whisper-small + Qwen1.5-1.8B

## 快速开始

### 环境要求

- MUSE Pi Pro开发板
- Python 3.8+
- ROS2 Humble
- ONNX Runtime 1.15+

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行系统

```bash
python src/main.py
```
